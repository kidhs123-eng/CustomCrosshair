# Custom Crosshair Overlay

Лёгкий оверлей прицела для Windows (аналог HudSight) на Python + PyQt6.
Рисует прицел поверх игры прозрачным окном, клики проходят насквозь. В память игры ничего не внедряется.

## Возможности

- Стили: классический `+`, T-образный, точка, круг с точкой, косой крест `✕`
- Свой прицел из PNG/SVG или нарисованный во встроенном пиксельном редакторе 64×64 (точность 1/8 пикселя, симметрия, масштаб)
- Цвет, прозрачность, обводка, длина, толщина, зазор, смещение
- Показ только когда активна выбранная игра (`.exe`) или поверх всех окон
- Автоподстройка под растянутое разрешение (stretched)
- Работа из трея, настройки сохраняются в `crosshair_config.json` рядом с программой

## Требования

- Windows 10/11
- Python 3.10+

```bash
pip install PyQt6 psutil pywin32
```

## Запуск

```bash
python main.py
```

## Сборка в .exe

```bash
pip install pyinstaller
pyinstaller --onefile --noconsole --name CustomCrosshair --hidden-import win32timezone main.py
```

Готовый файл: `dist/CustomCrosshair.exe`.

## Важно

- Игра должна работать в **оконном режиме без рамки** (borderless). В эксклюзивном полноэкранном режиме Windows не показывает поверх игры другие окна.
- Перед использованием в онлайн-играх проверьте их правила насчёт сторонних прицелов.
